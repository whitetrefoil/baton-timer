# Baton Timer 接力计时器

极简移动端多计时器，单个 `index.html`，无依赖、无需构建，直接用浏览器打开即可。

- 任意添加 / 删除计时器
- 点击名称即可改名
- 开始 / 暂停 / 复位，底部一键「全部复位」
- 同一时间只有一个计时器在跑：开始另一个时，正在跑的会自动暂停
- 状态保存在 localStorage，刷新或关掉页面后仍保留（运行中的计时器会继续计时）
- 自动适配深色模式

本地预览：`python3 -m http.server` 后访问 http://localhost:8000 ，或直接双击打开 `index.html`。
可部署到 GitHub Pages 等任意静态托管。
